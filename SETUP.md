# Publishing Abhay's new GitHub profile

1. Open the existing public `AbhayTiwari26/AbhayTiwari26` repository.
2. Replace the root `README.md` with the one in this package.
3. Add the entire `assets/` directory at the repository root, preserving every filename and path. Commit everything together. The visuals and animations use relative paths and will not display until the assets are committed.
4. Open the profile page and check the images on desktop and mobile. Reduced-motion visitors receive static versions of the animated banner and ticker.

**About the counter:** The Komarev `PROFILE VIEWS` badge counts image requests that reach its service, including refreshes. It is not a unique-human counter or a smooth live-ticking animation. GitHub does not run JavaScript inside profile READMEs, so animated number transitions would require hosting a separate dynamic image service. The small eye beside the badge is animated; the actual number is served by Komarev and updates on image loads.

**External services:** The view counter uses `komarev.com`. The optional collapsed LeetCode card uses `leetcard.jacoblin.cool`; everything else visual in this package is committed locally. If the LeetCode card fails to load, the plain LeetCode and HackerRank links still work. This package intentionally avoids the public `github-readme-stats.vercel.app` endpoint, which its maintainers say is best-effort and may be rate limited.

**Editing:** Artwork is generated by `build_assets.py` (included). Run `python build_assets.py` after changing copy, colors, or illustrations in the source. It requires Pillow. No API keys or hosted image service are needed for the local art.
